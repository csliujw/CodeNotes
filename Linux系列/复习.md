| mv     | 移动文件 | mv source target          |

| ln     | 创建链接 | ln -s source target       |
| apt    | 包管理   | apt install name          |

```shell
nohup java -jar demo1.jar &

```

```shell
$ ps aux | grep 'java' | grep -v 'grep'
$ jps
$ lsof -i:8080
```

杀死进程

```shell
$ kill -9 pid
$ pid=$(ps aux | grep 'java' | awk -F ' ' '{print $2}')
```

## shell 脚本

用 shell 脚本重启 demo1.jar 和 demo2.jar 怎么处理？

- 1.找到
- 2.判断是否在运行
  - 2.1运行中则杀死再启动
  - 2.2未运行则直接启动

```shell
d1=ps aux | grep 'demo1.jar' | awk -F ' ' '{print $2}'

if [ "$d1" != "" ] 
then
	kill -9 d1
	java -jar demo1.jar &
else
	java -jar demo1.jar &
fi
```

```shell
d1=ps aux | grep 'demo1.jar' | awk -F ' ' '{print $2}'
d2=ps aux | grep 'demo2.jar' | awk -F ' ' '{print $2}'


if [ "$d1" != "" ] 
then
	kill -9 d1
	java -jar demo1.jar &
else [ "$d1" == "" ]
	java -jar demo1.jar &
if

if [ "$d2" != "" ] 
then
	kill -9 demo2.jar
	java -jar demo2.jar &
else [ "$d2" == "" ]
	java -jar demo2.jar &
if
```



## git

安装 git

```shell
$ sudo apt update
$ sudo apt install git
```

初始化 git 仓库

```shell
$ mkdir learn-git
$ cd learn-git
$ git init
```

添加文件并创建提交

```shell
# 创建文件，添加
$ git add .
$ git commit -m "message"
```

创建分支，在分支中添加文件

```shell
$ git checkout -b 分支名称
```

合并两个分支

```shell
$ git merge other_branch
```
