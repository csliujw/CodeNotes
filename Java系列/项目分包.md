# JavaEE 项目分包情况

| 包                          | 说明                                                         |
| --------------------------- | ------------------------------------------------------------ |
| config                      | 所有的配置文件都写在这里。MP 的分页配置，自定义的字段填充；Controller的全局异常处理 |
| constant                    | 项目中需要使用的常量                                         |
| controller、mapper、service | 常规分层。项目体量不大，service 可不写接口（凤凰架构）       |
| exception                   | 自定义的异常都放这里                                         |
| util                        | 工具类都放这里                                               |
| domain                      | 存放普通Java对象。这里我区分了 DO、VO、Query。<br>一个 DO 对应一个数据库表。一个VO对应一个需要返回给前端的数据。Query对应前端传递过来的参数 <br>项目体量比较小，可以不区分的这么细致。很多表都有创建时间、更新时间、等公共字段，可以定义一个 BasePojo 。 |


配置文件有 3 个，application.yml、application-prod.yml、logback-spring.xml。
- application.yml 是所有环境通用的配置，比如数据库连接、mp 配置、mp sql 的日志配置（目前默认使用这个）。
- application-prod.yml 是生产环境专用的配置。
- logback-spring.xml 是日志配置文件。
